# 🚀 Быстрый запуск Tooxan

Скрипт для автоматического запуска **Tooxan** и автоматического ввода логина и пароля.

## ✨ Возможности

* Автоматический запуск Tooxan
* Автоматический ввод логина
* Автоматический ввод пароля
* Автоматическое нажатие кнопки входа
* Простая настройка

---

## 📦 Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/x0deex/tooxan-fast-open.git
cd tooxan-quick-launch
```

Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

---

## ⚙️ Настройка

Перед запуском обязательно измените следующие параметры в файле скрипта:

### Логин и пароль

```python
login = "Your_Username"
password = "Your_Password"
```

### Путь к Tooxan

```python
path_to_app = r"C:\Путь\К\Tooxan.exe"
```

Пример:

```python
path_to_app = r"D:\Programs\Tooxan\Tooxan.exe"
```

---

## ▶️ Запуск

Запустите скрипт:

```bash
python Tooxan.py
```

После запуска:

1. Откроется Tooxan
2. Скрипт подождёт несколько секунд
3. Введёт логин
4. Введёт пароль
5. Выполнит вход

---

## ⏳ Изменение задержки

Если программа открывается медленно, увеличьте время ожидания:

```python
time.sleep(5)
```

Например:

```python
time.sleep(10)
```

Если хотите чтоб запускалась быстро:

```python
time.sleep(3)
```

---

## ⚠️ Важно

* Во время работы скрипта не трогайте клавиатуру и мышь.
* Логин и пароль хранятся в открытом виде внутри скрипта.
* Используйте проект только на доверенных устройствах.
